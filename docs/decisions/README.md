# Decision Records

This directory is for rationale and assessment artifacts that explain why a direction was chosen.

Place docs here when they capture reviews, tradeoff analysis, status assessments, and acceptance/rejection reasoning.

Do not place initial planning drafts or raw ideation notes here.
