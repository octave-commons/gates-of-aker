# Documentation Taxonomy

This index defines the normalized documentation entry points used by migration scaffolding.

- [design/](design/) - Canonical architecture, mechanics, and system behavior references.
- [history/](history/) - Archival context, research, and prior-state records.
- [planning/](planning/) - Roadmaps, task plans, and implementation sequencing artifacts.
- [decisions/](decisions/) - Review and rationale records explaining why choices were made.
- [migration/](migration/) - Migration controls, inventory metadata, and classification rules.
- [../pseudo/](../pseudo/) - Non-integrated pseudo-code and prototype documents.

Notes:
- This scaffold only establishes destinations and navigation.
- Existing documentation remains in current locations until migration tasks move it.
